# Owner inputs required before store submission

Development can begin without these. Shipping cannot.

| Item | Proposed/default | Owner decision |
|---|---|---|
| Final app name | ECHO | Confirm trademark/store availability |
| iOS bundle identifier | `com.yourcompany.echo` | Replace with final value |
| Android application ID | `com.yourcompany.echo` | Replace with final value |
| Apple developer account | Unknown | Confirm active team ID and certificates |
| Google Play developer account | Unknown | Confirm active account |
| Support email | Unknown | Supply public support address |
| Website | Unknown | Supply public URL |
| Privacy policy URL | Not supplied | Legal review + publish URL |
| Terms URL | Not supplied | Legal review + publish URL |
| Subscription | No paywall in this flow | Decide free, trial and pricing |
| Analytics vendor | Privacy-first, no journal content | Choose vendor or none |
| Crash reporting | Redacted diagnostics only | Choose vendor |
| AI reflection provider | Product decision | Confirm provider, region and retention |
| Cloud backup backend | Optional/private | Confirm backend and encryption model |
| Launch countries | Global English proposed | Confirm availability |
| Age rating | 12+ proposed; not medical care | Confirm with counsel/store questionnaire |
| Hindi/localization | English v1; Hindi later | Confirm roadmap |
| Data deletion SLA | Immediate local, ≤30 days remote proposed | Confirm policy |
