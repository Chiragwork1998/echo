# Background regeneration guidance

Use the corresponding golden screen as a visual reference. Generate a 9:19.5 vertical, edge-to-edge cinematic Spiti landscape with the same camera position and landmark placement. Remove every phone frame, status bar, logo, heading, label, control, card, progress mark, button and text. Fill removed regions with continuous natural landscape. Preserve negative space where the UI sits. Avoid people, letters, symbols, watermarks, horror lighting and fantasy architecture.

Night should keep the same geometry as Day. Prefer deterministic indigo color grading plus `moon-stars.svg` and warm-window accents. If Night is regenerated independently, match Day landmarks and crop precisely.
